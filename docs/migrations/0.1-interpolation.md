# Render interpolation migration

Scene version 3, authoritative `Transform`/`GlobalTransform`, and exact
`Engine::extract` remain compatible. Games opt selected fixed-simulation local
transforms into smoothing by adding `InterpolateTransform`; children inherit
their parent's presented motion. The examples now use this engine primitive.

`BrowserApp::frame` selects interpolated extraction from the fixed-clock fraction.
Paused `step`, `render`, and `capture` still render exact current state. Agents
can request `present { alpha }` or `capture { alpha }` to examine an intermediate
pose. `benchmark` adds `mode: "present"` at alpha 0.5. All require pause and are
temporary controls; they do not change authored source or advance simulation.

Use `reset_interpolation` for teleports and inspect `PresentedTransform` separately
from gameplay transforms. New `PresentationState` observations distinguish the
prepared pose from the current authoritative tick. Rebuild host and Wasm together
to pick up generated control schemas and projections.

History storage adds bounded CPU memory and work. Standard interpolation adds
one fixed tick of visual delay. See [decision 008](../adr-008-render-interpolation.md)
for ownership and [benchmarking](../benchmarking.md) for measurements.
