# Migrating to scene files

[Decision 030](../adr-030-scene-files.md) lets version 7 scenes reference
image and mesh-buffer files.

- `SceneTexture::width`, `height` and `rgba8` are `Option`s beside the new
  `uri`; build textures with `SceneTexture::inline` or `SceneTexture::file`.
- `MeshSource::Buffer { uri }` reads an `EMB1` buffer; `encode_mesh_buffer`
  writes one.
- Load documents that reference files with `SceneDocument::files`, a
  `SceneFiles` holding their decoded contents, and `instantiate_with` (or
  `validate_with`). `instantiate` still works for documents without files.
- The playground's `create` and `reload_scene` take a `SceneFileSet`, and
  `dev_reload` an optional one; hosts build it with `loadSceneFiles`.
  Hosts that pass their own scene reload adapter add a `files` loader.
- Scene sources may be 64 MiB and have no entity, mesh, material, texture,
  prefab or tag count limit; the `count_limit` error no longer occurs.
