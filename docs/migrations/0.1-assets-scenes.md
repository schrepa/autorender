# Asset and scene API migration

The workspace remains an unpublished 0.1 development SDK. Bevy stays pinned at 0.19.1.

- `Cube { color }` still works. For shared geometry/material ownership, insert `Mesh` and `Material` in `AssetLibrary` and use `Mesh3d { mesh, material }` with `Transform`.
- `RenderInstance` now includes a typed `mesh` handle, and `RenderSnapshot` includes owned `meshes` and `missing_assets`. Prefer `Engine::extract`; low-level snapshot constructors must include every referenced mesh exactly once.
- Renderer draw count is now the number of referenced meshes, not always one. Upload bytes include first-time geometry upload. New residency counters expose cache growth and retirement.
- `engine::camera::FlyCameraPlugin` replaces the demo-local camera controller. Existing `Presentation` and `FixedSimulation` schedule names remain unchanged.
- `ActionInput`/`ActionId` add fixed-tick action edges without changing analog `InputState`. Look deltas are CSS pixels, correcting the original input documentation.
- Browser stats use the shared generated `BrowserStats` type. Regenerate bindings with `cargo xtask build`; generated packages are not hand-maintained.
- Scene format version 1 is the first persisted format. Runtime handles and Bevy entities are never its identifiers. There is no prior saved format to migrate.
