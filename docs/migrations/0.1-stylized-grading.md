# Migrating to stylized grading

[Decision 027](../adr-027-stylized-grading.md) adds contrast, vibrance and
split toning to the grade, keeps bright hues through the tone curve, and
retunes the atmosphere presets.

- Every scene looks different, most of all where fog was heavy: presets are
  more saturated and contrasted, with thinner, later fog. Scenes that name a
  preset take its new values.
- `Atmosphere` has four new public fields: `contrast`, `vibrance`,
  `shadow_tint` and `highlight_tint`. Struct literals add them or use
  `..Atmosphere::golden_hour()` (or another preset). Neutral values are
  contrast 1, vibrance 0 and white tints.
- To come close to an earlier preset, override these fields (neutral grade
  otherwise); the tone curve changed, so the result is near, not identical:

  | Preset | Earlier values |
  | --- | --- |
  | `day` | sun_color [2.2, 2.05, 1.8], zenith [0.16, 0.34, 0.85], horizon [0.62, 0.74, 0.92], fog_start 40, fog_density 0.0016, fog_max 0.75, exposure 0.9, saturation 1.1 |
  | `golden_hour` | zenith [0.12, 0.22, 0.6], horizon [1.05, 0.62, 0.45], fog_start 40, fog_density 0.0022, fog_max 0.75, exposure 0.85, saturation 1.15 |
  | `dusk` | zenith [0.05, 0.05, 0.24], horizon [0.95, 0.36, 0.48], fog_start 40, fog_density 0.0026, fog_max 0.78, saturation 1.25 |
  | `night` | fog_density 0.0028, fog_max 0.85, saturation 1.15 |

- Scene version 6 authors the four fields in `environment.atmosphere`;
  versions 1 to 5 refuse them with `version_required`.
- Custom shaders that bind the lighting uniform read 160 bytes: `grade`
  (contrast, vibrance), then the luminance-normalized `shadow_tint` and
  `highlight_tint` after `effects`.
