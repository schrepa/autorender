# Migrating to scene atmosphere

[Decision 018](../adr-018-atmosphere-and-stylized-lighting.md) replaces the
mesh shader's fixed lighting with the `Atmosphere` resource.

- Scenes look different by default: a golden-hour sky, sky-colored fog and
  tone mapping. Insert or edit `Atmosphere` to choose a look, e.g.
  `*world.resource_mut::<Atmosphere>() = Atmosphere::night();`, or set its
  fields for a custom palette.
- `RenderSnapshot` has two new public fields, `camera_position` and
  `atmosphere`. Code building snapshots with struct literals adds them or
  uses `..Default::default()`; engine extraction fills both.
- `Camera::eye` returns the position a view-projection looks from, falling
  back like `Camera::view_projection` for a non-finite position.
