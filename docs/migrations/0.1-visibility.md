# Visibility and benchmark migration

Scene JSON remains version 3; no authored fields or revisions need changing.
Mesh bounds are computed once from validated runtime geometry.

`EngineConfig` adds `frustum_culling: bool`, defaulting to `true`. Rust literals
should specify it or use `..EngineConfig::default()`. Disable through
`Engine::set_frustum_culling(false)` when a workload intentionally measures all
renderables. Tests of world/entity count should use `render_candidates`, not the
number of instances submitted to the renderer.

`RenderSnapshot` adds `render_candidates`, `visible_instances` and
`culled_instances`. Existing `instances` contains only visible, admitted objects.
Source mesh/texture lists also retain culled objects' assets. Low-level renderer
clients may supply sources without draw instances: this retains an existing GPU
resource but does not upload a new one. Removing the source retires it. Existing
byte/count validation applies to the complete source list.

Browser stats and development replies add the counters, missing/dropped counts,
culling mode and instance upload bytes. Rebuild Wasm bindings and host together.
`Mesh3d` inspection includes `local_bounds` or null if the mesh is absent. Paused
`camera`, `culling` and `benchmark` commands are described by the generated
`BrowserControl` schema; their changes are temporary and never persist scene edits.

Benchmarks record CPU phase time and paced frame intervals, not GPU timestamps.
Keep sample, warm-up, viewport, browser/device and workload settings identical for
comparisons. Step mode advances simulation and clears input; use a fresh session
for controlled repeated runs. See [benchmarking](../benchmarking.md).
