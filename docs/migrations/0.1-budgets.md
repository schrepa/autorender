# Migrating to budgets instead of caps

[Decision 029](../adr-029-budgets-and-device-limits.md) turns capacity
constants into settings with no budget by default.

- `Particles::max_particles` and `LocalLights::max_lights` are `Option<u32>`
  (`None`, the default, draws every emitter and light); scene version 6
  omits them for no budget. `LocalLights::lights_per_cluster` is an
  `Option<u32>` budget too: cluster lists hold every light by default, and
  scenes that set 32, the former fixed length, keep that budget.
- Removed constants: `MAX_EMITTERS`, `MAX_PARTICLES` (one emitter's
  particles are bounded by `MAX_EMITTER_PARTICLES`), `MAX_LOCAL_LIGHTS`, and
  the renderer's `MAX_INSTANCES` and `MAX_RESIDENT_*`. Snapshots over the
  old renderer limits render; only the GPU's buffers bound instances.
- `EngineConfig` has `asset_budget` and `max_transform_nodes`, and
  `max_render_instances` defaults to `usize::MAX` (no budget). Struct
  literals add them or use `..EngineConfig::default()`.
- `AssetBudget::default()` admits everything; `AssetLibrary::set_budget`
  limits later admissions. `MAX_TEXTURE_DIMENSION` is 8,192.
- `MAX_TRANSFORM_NODES` is the 32-bit index bound; set a budget with the
  `TransformNodeLimit` resource. `MAX_TRANSFORM_EDITS` stays 262,144.
- Browser stats and `rendering` add `dropped_particles`.
