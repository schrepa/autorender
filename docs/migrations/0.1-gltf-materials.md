# Migrating to glTF materials

[Decision 031](../adr-031-gltf-materials.md) makes materials glTF 2.0
metallic-roughness materials.

- `RenderInstance::texture` is now `RenderInstance::material`: for a
  material with maps (`Material::has_maps`), the first extracted material
  with an equal `Material::binding`, listed in the new
  `RenderSnapshot::materials` with its textures in `RenderSnapshot::textures`.
  Instances of materials without maps set `None`. Decide transparency with
  `RenderInstance::is_transparent`, passing the instance's listed material.
- `Material::textured` still makes a clamped base color texture;
  `Material::texture` still returns its handle. The other maps, samplers and
  transforms are `with_base_color_texture`, `with_metallic_roughness_texture`,
  `with_normal_texture`, `with_occlusion_texture`, `with_emissive`,
  `with_emissive_texture`, `with_alpha_mode` and `with_double_sided`, taking
  `TextureRef`s (`TextureRef::new(texture).with_sampler(..).with_transform(..)`).
- `Material::is_transparent` follows the alpha mode: `with_opacity` below 1
  still blends, but `AlphaMode::Mask` materials with an opacity below 1 are
  opaque, and `AlphaMode::Blend` materials blend at opacity 1.
- `SceneMaterial::texture` is a `SceneMap` (an ID or a `SceneTextureMap`);
  `SceneMaterial` gained the version 8 fields. Construct plain IDs with
  `Some("id".into())`.
- Scene version 8 plain texture IDs repeat; version 7 and earlier ones clamp.
  To move a document to version 8 without changing it, call
  `SceneDocument::upgrade` (imports into existing scenes do).
- `engine_assetc::import_glb` and `import_glb_prefab` return `Imported`: the
  document, the image and mesh-buffer files to write beside it, and the
  ignored extensions. `encode_mesh_buffer` accepts `SceneVertex`es too.
