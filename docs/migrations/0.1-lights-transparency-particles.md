# Migrating to local lights, shafts, reflections, transparency and particles

Decisions [023](../adr-023-local-lights.md), [024](../adr-024-sun-shafts.md),
[025](../adr-025-screen-space-reflections.md) and
[026](../adr-026-transparency-and-particles.md) add point and spot lights,
sun shafts, screen-space reflections, transparent materials and particles.

- Nothing changes until you use them: `LocalLights` and `Particles` are
  inserted by default and cost nothing without `LocalLight` or
  `ParticleEmitter` components; `SunShafts` and `Reflections` are opt-in
  resources (insert them, or author them in a scene environment).
- `RenderInstance::color[3]` is now the opacity: below 1 the instance draws
  in the transparent pass and casts no shadow. Materials still require alpha
  1 from `Material::new`; use `Material::with_opacity`. `Cube` colors ignore
  alpha, as the renderer always did.
- `RenderSnapshot` has `sun_shafts`, `reflections`, `local_lights`,
  `lights`, `dropped_lights`, `particles`, `emitters` and
  `dropped_particles`. Code building snapshots with struct literals adds
  them or uses `..Default::default()`; engine extraction fills them.
- `SceneEnvironment` has `local_lights`, `sun_shafts`, `reflections` and
  `particles`, and `EnvironmentSettings` their resolved values; the
  `environment` control accepts the same sections. Struct literals add
  them. A scene environment that omits `sun_shafts` or `reflections` removes
  those resources when instantiated.
- Scene version 6 authors material `opacity`, entity `light` and
  `particles`, and the new environment sections. Importing now writes
  version 6; versions 1 to 5 keep their meaning.
- `RenderStats` has `lights`, `sun_shafts`, `reflections`,
  `transparent_draws` and `particles`; browser stats add `local_lights`,
  `dropped_lights`, `lights_visible`, `light_cluster_overflow`,
  `sun_shafts`, `reflections`, `transparent_draws` and `particles`.
  `draw_calls` counts transparent batches too.
- Transparent draws of temporally antialiased frames ignore the moving-slot
  bit of visible IDs: custom shaders reading `vs_affine` slot streams mask
  `MOVED_SLOT`.
